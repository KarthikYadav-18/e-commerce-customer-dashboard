📌 Project Overview
This project presents an interactive Power BI dashboard built using an E-commerce Customer Behavior dataset.
The dashboard provides insights into sales performance, customer behavior, product trends, returns, and churn analysis.

The goal is to transform raw data into meaningful business insights using data visualization and analytics techniques.

🎯 Objectives
Analyze customer purchasing behavior across product categories

Identify sales trends over time

Evaluate payment methods and demographic impact on sales

Analyze returns and product performance

Study customer churn and segmentation for business insights
